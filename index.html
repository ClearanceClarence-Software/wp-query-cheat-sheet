Basic usage

Build an array of arguments, pass it to WP_Query, loop over the results, then reset post data so template tags point back at the main query.

01

Author

Docs ↗

Show posts by, or not by, certain authors.

ParameterTypeDescription
authorintstringAuthor ID, or a comma-separated list of IDs. Prefix an ID with - to exclude it: '-1,-2'.
author_namestringThe author's user_nicename, not their display name.
author__in 3.7+int[]Posts by any of these author IDs.
author__not_in 3.7+int[]Posts by none of these author IDs.
02

Category

Docs ↗

Show posts in, or not in, certain categories.

ParameterTypeDescription
catintstringCategory ID, children included. Comma-separate several IDs; prefix with - to exclude: '-12,-34'.
category_namestringCategory slug, children included. 'staff,news' matches any; 'staff+news' matches all.
category__andint[]Posts in all of these categories.
category__inint[]Posts in any of these categories. Children are not included.
category__not_inint[]Posts in none of these categories. Children are not included.

Tag

Docs ↗

Show posts with, or without, certain tags.

ParameterTypeDescription
tagstringTag slug. 'bread,baking' matches any; 'bread+baking' matches all.

tag__andint[]Posts with all of these tag IDs.
tag__inint[]Posts with any of these tag IDs.
tag__not_inint[]Posts with none of these tag IDs.
tag_slug__andstring[]Posts with all of these tag slugs.
tag_slug__instring[]Posts with any of these tag slugs.
04

Taxonomy

Docs ↗

Query any taxonomy, including custom ones, with boolean logic between clauses.

ParameterTypeDescription
tax_query 3.1+arrayAn array of clause arrays. Clauses can be nested, each with its own relation.

Keys inside tax_query

ParameterTypeDescription
relationstringHow clauses combine: 'AND' (default) or 'OR'. Goes in the outer array.
taxonomystringTaxonomy name. Optional when field is 'term_taxonomy_id'.
fieldstringWhat terms holds: 'term_id' (default), 'slug', 'name' or 'term_taxonomy_id'.
termsintstringarrayThe term or terms to match.
include_childrenboolInclude child terms of hierarchical taxonomies. Default true.
operatorstring'IN' (default), 'NOT IN', 'AND', 'EXISTS' or 'NOT EXISTS'.
Note

tax_query takes an array of arrays, even for a single clause.

Note

When tax_query is set and post_type is not, post_type defaults to 'any'.

05

Post & Page

Docs ↗

Fetch specific posts or pages by ID, slug, title or parent.

ParameterTypeDescription
pintPost ID.
namestringPost slug.
title 4.4+stringPost title, exact match.
page_idintPage ID.
pagenamestringPage slug. For a child page use 'parent/child'.
attachment_idintAttachment ID.
post_name__in 4.4+string[]Posts with any of these slugs.
post_parentintChildren of this ID. Use 0 for top-level entries only. Hierarchical post types only.
post_parent__in 3.6+int[]Posts whose parent is any of these IDs.
post_parent__not_in 3.6+int[]Posts whose parent is none of these IDs.
post__inint[]Only these post IDs. Sticky posts are still prepended unless ignore_sticky_posts is set.
post__not_inint[]Exclude these post IDs. Must be an array; a comma-separated string does not work.
menu_orderintPosts with exactly this menu order.
Watch out

An empty post__in array returns all posts, not none. Check for an empty list before querying.

Watch out

post__in and post__not_in cannot be combined: post__in wins and the other is ignored.

Note

post__not_in scales poorly on large sites. Filtering IDs out in PHP is often faster.

07

Post Type

Docs ↗

Choose which post types to return.

ParameterTypeDescription
post_typestringstring[]A post type or an array of them. Default 'post', or 'any' when tax_query is set.

Values

post
A post.
page
A page.
revision
A revision.
attachment
Media. Attachments use the 'inherit' status, so set post_status to 'inherit' or 'any'.
nav_menu_item
A classic navigation menu item.
wp_block
A synced pattern (reusable block).
wp_template
A block template.
wp_template_part
A block template part.
wp_navigation
A navigation block menu.
any
Every type except revisions and types with exclude_from_search. Cannot be used inside an array.

Post Status

Docs ↗

Choose which statuses to return.

ParameterTypeDescription
post_statusstringstring[]A status or an array of them. Default 'publish', plus 'private' for users who can read private posts.

Values

publish
Published.
pending
Pending review.
draft
Draft.
auto-draft
Newly created, no content yet.
future
Scheduled.
private
Visible only to users with the right capability.
inherit
Revisions and attachments.
trash
In the trash.
any
Every status except 'trash' and 'auto-draft'. Cannot be used inside an array.

10

Pagination

Docs ↗

Control how many posts are returned and which page of them.

ParameterTypeDescription
posts_per_pageintPosts per page. Use -1 for all. In feeds this is replaced by the posts_per_rss option.
nopagingboolReturn all posts, no paging. Default false.
pagedintPage number, usually get_query_var( 'paged' ).
pageintPage number on a static front page. Also the page of a post split with <!--nextpage-->.
posts_per_archive_pageintOverrides posts_per_page when is_archive() or is_search() is true.
offsetintNumber of posts to skip.
ignore_sticky_posts 3.1+boolStop sticky posts being moved to the front. They still appear in their natural position. Default false.
Watch out

offset overrides paged and breaks pagination. It is also ignored when posts_per_page is -1.

Note

On a page template used as a static front page, read get_query_var( 'page' ) instead of 'paged'.

Order & Orderby

Docs ↗

Sort the results.

ParameterTypeDescription
orderstring'DESC' (default) or 'ASC'.
orderbystringarrayOne value, several separated by spaces, or an array of field => direction pairs (since 4.0). Default 'date', or 'relevance' when searching.
meta_typestringCast applied to meta_key values when sorting by 'meta_value'. Same types as meta_query.

orderby values

none
No order.
ID
Post ID. Note the capitals.
author
Author ID. Also 'post_author'.
title
Title. Also 'post_title'.
name
Slug. Also 'post_name'.
type
Post type. Also 'post_type'.
date
Publish date. Also 'post_date'.
modified
Last modified date. Also 'post_modified'.
parent
Parent ID. Also 'post_parent'.
rand
Random. 'RAND(5)' uses a seed (since 4.5). Slow on large tables.
comment_count
Number of comments.
relevance
Search relevance: full phrase, then all terms in title, then any term in title, then phrase in content.
menu_order
Page order, then attachment order.
meta_value
Value of meta_key, sorted as text unless meta_type is set.
meta_value_num
Value of meta_key, sorted as a number.
post__in
Keep the order of the post__in array. Ignores order.
post_name__in
Keep the order of the post_name__in array (since 4.6).
post_parent__in
Keep the order of the post_parent__in array (since 4.6).
clause key
The key of a named meta_query clause (since 4.2).
12

Date

Docs ↗

Filter by publish or modified date, from simple values to full date ranges.

ParameterTypeDescription
yearintFour-digit year.
monthnumintMonth, 1 to 12.
wintWeek of the year, 0 to 53. Depends on the start_of_week option.
dayintDay of the month, 1 to 31.
hourintHour, 0 to 23.
minuteintMinute, 0 to 59.
secondintSecond, 0 to 59.
mintYear and month together, e.g. 202611.
date_query 3.7+arrayAn array of date clauses. Clauses can be nested.

Keys inside date_query

ParameterTypeDescription
relationstring'AND' (default) or 'OR'. Top level only.
columnstringColumn to compare: 'post_date' (default), 'post_date_gmt', 'post_modified', 'post_modified_gmt'. Top level or per clause.
afterstringarrayA strtotime() string, or an array of year, month, day.
beforestringarrayA strtotime() string, or an array of year, month, day.
inclusiveboolInclude the exact after and before dates. Default false.
year, month, week, dayintint[]Calendar parts: month 1–12, week 1–53, day 1–31.
dayofyearintint[]Day of the year, 1 to 366.
dayofweekintint[]Day of the week, 1 (Sunday) to 7.
dayofweek_iso 4.1+intint[]ISO day of the week, 1 (Monday) to 7.
hour, minute, secondintint[]Time parts: 0–23, 0–59, 0–59.
comparestring= (default), !=, >, >=, <, <=, IN, NOT IN, BETWEEN, NOT BETWEEN. Array values need one of the last four.
13

Custom Field

Docs ↗

Filter by post meta, with simple keys or a full meta_query.

ParameterTypeDescription
meta_keystringstring[]Meta key or keys.
meta_valuestringstring[]Meta value or values.
meta_comparestringOperator for meta_value. Same values as compare below. Default '=', or 'IN' for an array.
meta_compare_key 5.1+stringOperator for meta_key. Same values as compare_key below.
meta_typestringCast for meta_value. Same values as type below.
meta_type_key 5.3+stringCast for meta_key. Only 'BINARY'.
meta_query 3.1+arrayAn array of meta clauses. Clauses can be nested and named.

Keys inside meta_query

ParameterTypeDescription
relationstring'AND' (default) or 'OR'.
keystringstring[]Meta key or keys.
valuestringstring[]Value or values. Leave it out for EXISTS and NOT EXISTS. Arrays only work with IN, NOT IN, BETWEEN, NOT BETWEEN.
comparestring= (default), !=, >, >=, <, <=, LIKE, NOT LIKE, IN, NOT IN, BETWEEN, NOT BETWEEN, REGEXP, NOT REGEXP, RLIKE, EXISTS, NOT EXISTS.
typestring'CHAR' (default), 'NUMERIC', 'BINARY', 'DATE', 'DATETIME', 'DECIMAL', 'SIGNED', 'TIME', 'UNSIGNED'. DECIMAL and NUMERIC accept precision, e.g. 'DECIMAL(10,2)'.
compare_key 5.1+stringOperator for the key: =, !=, LIKE, NOT LIKE, IN, NOT IN, REGEXP, NOT REGEXP, RLIKE, EXISTS, NOT EXISTS.
type_key 5.3+stringCast for the key. Only 'BINARY', for case-sensitive regex.
Note

Give a clause a string key to sort by it: 'orderby' => 'price_clause'.

Note

meta_value_num is an orderby value only. To filter numerically, set type to 'NUMERIC'.

Watch out

DATE with BETWEEN only works when dates are stored as YYYY-MM-DD.

16

Caching

Docs ↗

Trade cache priming for speed when you don't need the extra data.

ParameterTypeDescription
cache_resultsboolCache post objects and, since 6.1, the query result itself. Default true.
update_post_meta_cacheboolPrime the meta cache. Turn off if you won't read meta. Default true.
update_post_term_cacheboolPrime the term cache. Turn off if you won't read terms. Default true.
update_menu_item_cache 6.1+boolPrime caches for the objects nav menu items point to. Default false.
lazy_load_term_meta 4.6+boolPrime term meta lazily. Defaults to update_post_term_cache.
no_found_rowsboolSkip counting total rows. Faster, but found_posts and max_num_pages become 0, so pagination stops working. Default false.
Note

Since 6.1 identical queries in one request skip the database. With a persistent object cache, that holds across requests too.

Search

Docs ↗

Search post content, with control over columns and matching.

ParameterTypeDescription
sstringSearch terms. Prefix a term with - to exclude it: 'pillow -sofa'. The prefix can be changed with the wp_query_search_exclusion_prefix filter.
search_columns 6.2+string[]Columns to search: 'post_title', 'post_excerpt', 'post_content'. Default all three.
exactboolMatch the whole field, without wildcards. Default false.
sentenceboolSearch the input as one phrase instead of separate terms. Default false.
18

Return Fields

Docs ↗

Return lighter results than full post objects.

ParameterTypeDescription
fieldsstringWhat to return. Anything other than the values below returns full post objects.

Values

''
Full WP_Post objects. Default.
ids
An array of post IDs.
id=>parent
From get_posts() or $query->query(): parent IDs keyed by post ID. In $query->posts: objects with only ID and post_parent.

Filters

Docs ↗

Hook into the SQL that WP_Query builds.

ParameterTypeDescription
suppress_filtersboolSkip the posts_* SQL filters. Default false, but get_posts() sets it to true.

Common filters

posts_where
Change the WHERE clause.
posts_join
Change the JOIN clause.
posts_orderby
Change the ORDER BY clause.
posts_clauses
Change all clauses at once.
posts_pre_query
Return posts yourself and skip the database.
found_posts
Adjust the total, for example after using offset.

No parameters match that filter.
